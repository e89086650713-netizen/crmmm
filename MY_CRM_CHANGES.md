# Изменения MyCRM v1

На базе SelfCRM.

## Главная
- «Начните с первого клиента» → «@A60carat, здравствуйте, сервис готов к работе».
- «Добавьте клиента, чтобы создавать заказы и видеть историю работы.» → «Добавьте клиента, вид работы и начните работать».
- Быстрое действие «Товар» → «Прайс, сметы».
- Нижний раздел «Товары» полностью заменён на «Прайс, сметы» и открывает отдельный экран с прайсами и шаблонами смет.

## Прайс и сметы
Добавлен новый экран «Прайс, сметы».
- Раздел «Прайс» для Excel-файлов.
- Раздел «Шаблоны смет» для Excel-файлов под разные виды работ.
- Загрузка `.xlsx`, `.xls`, `.xlsm`.
- Пользовательское название файла.
- Скачивание сохранённых файлов.
- Удаление файлов.
- Файлы сохраняются локально в IndexedDB браузера/веб-приложения; сервер не нужен.

Старая логика товаров сохранена внутри проекта для совместимости со складом и существующими заказами, но раздел «Товары» убран из основного меню и заменён экраном «Прайс, сметы».

## Версия 3 — поля заказа
- В заказ добавлено поле «Вид работы» сразу после даты.
- Поле «Себестоимость» из формы позиции убрано.
- Вместо блока себестоимости добавлен раздел «Смета» с загрузкой Excel (.xlsx/.xls/.xlsm), скачиванием, удалением и заменой файла.
- Смета хранится локально в IndexedDB и привязана к конкретному заказу.
- В карточке сохранённого заказа отображаются вид работы и прикреплённая смета.

## v4 — склад инструментов и материалов
- Раздел «Склад» переделан под инвентаризацию инструментов, материалов и расходников.
- Добавлены категории, поиск по названию/коду/инвентарному номеру, фото, количество, инвентарный номер и статус «В использовании» с местом/человеком.
- Добавлен сканер через браузерный BarcodeDetector: он использует все форматы, которые поддерживает конкретный браузер/устройство, с ручным вводом как запасным вариантом.
